# Obsidian vault

This directory is the **committed** memory system for the repository.

- Commit everything under `docs/obsidian/` except editor state in `.obsidian/`.
- Sessions: `Sessions/`
- Active work snapshot: `CURRENT_WORK.md`
- Do not use a root `CURRENT_WORK.md` or `CONTEXT.md` as source of truth (those stay local/ignored).
